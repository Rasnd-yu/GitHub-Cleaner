# Developer collection data

The user records produced by the collection pipeline in the parent directory, stored
compressed because the expanded form occupies 94 MB.

| Archive | Expands to | Compressed | Expanded |
| --- | --- | ---: | ---: |
| `data.tar.gz` | `../data/` | 14 MB | 94 MB, 6 files |

## Contents

| File | Size | Produced by |
| --- | ---: | --- |
| `github_repos_hot_wd.json` | 43 MB | input to `collectors/github_repos_contributors.py` |
| `users.json` | 25 MB | the unified user store written by every collector |
| `famous_users_raw.json` | 25 MB | users before the follower threshold is applied |
| `famous_users_filtered.json` | 2.4 MB | output of `filter_users.py`, the well-known developer corpus |
| `github_leaderboard.json` | 622 B | seed list from `get_github_leaderboard.py` |
| `gitstar_ranking_users_top100.json` | 1.6 KB | seed list from `get_gitstar_ranking.py` |

Run-time state written by the pipeline is deliberately excluded, as are the per-user
activity characteristics and the detection output that feeds the user analysis; those
are regenerated by running the pipeline rather than distributed with it.

## Extraction

Run from the `data_collect_developers/` directory; the archive recreates the path the
collectors expect:

```bash
cd data_collect_developers
tar -xzf datasets/data.tar.gz
```

## Integrity

```bash
cd data_collect_developers/datasets
sha256sum -c SHA256SUMS
```
